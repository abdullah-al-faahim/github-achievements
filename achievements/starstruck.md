## How it works

Starstruck goes to the **owner** of a repository once that repository reaches a star threshold. Stars are not added up across repositories. Ten repos with 15 stars each earn nothing, but one repo with 16 stars earns the badge.

| Tier | Stars on one repo | Label |
|---|:-:|:-:|
| Default | 16 | – |
| Bronze | 128 | `x2` |
| Silver | 512 | `x3` |
| Gold | 4,096 | `x4` |

## How to earn it

1. **Build something useful and narrow.** Small CLI tools, curated `awesome-*` lists, cheat sheets, templates and starter kits get starred far more often than large apps.
2. **Write a strong README** with a one-line pitch, a screenshot or GIF, install steps and a usage example.
3. **Add topics** (repo → ⚙️ About → Topics) so the repo shows up in GitHub topic search.
4. **Share it where your audience already is:** relevant subreddits, Hacker News "Show HN", dev.to, Discord communities, X/Bluesky/LinkedIn.
5. **Keep it alive.** Respond to issues, tag releases, and accept contributions. Active repos keep getting stars.

## Good to know

- Stars on a repo that belongs to an **organization** count toward the org, not toward you, even if you created it.
- If the stars drop below a threshold later, you keep the badge.
- Stars from bought or fake accounts break GitHub's Acceptable Use Policies, and GitHub removes them in bulk.
