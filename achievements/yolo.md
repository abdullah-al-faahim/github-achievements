# YOLO

*Merged a pull request without a code review.*

</div>

| | |
|---|---|
| **Status** | ✅ Active |
| **Tiers** | Single tier |
| **What counts** | Merging a PR that had **no approving review** |
| **Effort** | ⭐ A few minutes |

## How to earn it

The most reliable way, based on community testing:

1. In a repository you own, add a collaborator (Settings → Collaborators), or use a repo where you already have one.
2. Create a branch, make a change and open a pull request.
3. In the PR sidebar, **request a review** from that collaborator.
4. **Merge the PR before they review it.**

```bash
gh pr create --fill --reviewer <collaborator>
gh pr merge --merge --delete-branch
```

On solo repos, many people also get the badge just by merging their own PR with no reviewer at all, so try that first.

## Good to know

- Branch protection rules that require reviews will stop you from merging. Do this on an unprotected branch, or as an admin who can bypass the rules.
- The collaborator doesn't need to do anything. They only need to be requestable.
