# Public Sponsor

*Sponsored an open source contributor through GitHub Sponsors.*

</div>

| | |
|---|---|
| **Status** | ✅ Active |
| **Tiers** | Single tier |
| **What counts** | A **public** sponsorship of a user or organization on GitHub Sponsors |
| **Effort** | ⭐⭐ Costs money (from $1) |

## How to earn it

1. Find someone to support:
   - A **💖 Sponsor** button on a repo you use
   - [github.com/sponsors/explore](https://github.com/sponsors/explore), which lists maintainers of your own dependencies
2. Open their sponsor page and pick a tier. Many maintainers offer a **$1/month** tier or a custom one-time amount.
3. Under **Who can see your sponsorship?** choose **Public**. Private sponsorships don't unlock the badge.
4. Complete checkout.

## Good to know

- One-time sponsorships count as well as monthly ones.
- You keep the badge if you cancel the sponsorship later.
- Sponsoring through an organization account gives the badge to the org, not to you.
