## How it works

In any Discussions category that uses the **Q&A** format, the person who asked (or a maintainer) can mark one reply as the answer. Every reply of yours that gets marked counts toward Galaxy Brain.

| Tier | Accepted answers | Label |
|---|:-:|:-:|
| Default | 2 | – |
| Bronze | 8 | `x2` |
| Silver | 16 | `x3` |
| Gold | 32 | `x4` |

## How to earn it

1. Browse unanswered questions:
   - [github.com/orgs/community/discussions](https://github.com/orgs/community/discussions) (GitHub's own community forum, which gets a lot of traffic)
   - The **Discussions → Q&A** tab of tools you already know well
2. Filter by **Unanswered** and pick questions you can solve completely.
3. Write a clear answer with steps, a code block and links to docs.
4. Follow up. Askers often forget to mark answers, so a polite *"If this solved it, could you mark it as the answer?"* helps.

## Good to know

- Only categories in **Q&A** format have the "Mark as answer" button.
- Answering your own question and marking it **does not count**.
- If an answer is unmarked later, it can stop counting toward your next tier.
