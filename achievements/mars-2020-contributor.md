# Mars 2020 Helicopter Contributor

*Contributed code to repositories used in the Mars 2020 Helicopter Mission.*

</div>

| | |
|---|---|
| **Status** | 🧊 Retired, can't be earned anymore |
| **Tiers** | Single tier |
| **Awarded** | April 2021, after Ingenuity's first flight |

## What it was

NASA's **Ingenuity** helicopter, the first aircraft to fly powered on another planet, relied on open source software. JPL shared a list of the open source projects and versions the mission used, including F´ (F Prime), Python, NumPy, SciPy, Matplotlib, Linux and many more.

GitHub gave this badge to everyone who had authored a commit in those repositories **in the versions the mission used**. About 12,000 developers received it.

## Can I still get it?

No. GitHub's documentation says the event has ended and the badge is no longer available.
