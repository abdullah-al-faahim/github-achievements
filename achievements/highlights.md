# ✨ Profile highlights

*The badges that appear under **Highlights** in your profile sidebar.*

</div>

Highlights are separate from achievements. Achievements come from activity, while highlights come from **plans, programs and roles**. None of them have tiers.

| | Highlight | How you get it | Can anyone get it? |
|:-:|---|---|:-:|
| <img src="../assets/highlights/pro.svg" width="56"> | **PRO** | Subscribe to **GitHub Pro**, or get it free through the GitHub Student Developer Pack or GitHub Education for teachers | ✅ |
| <img src="../assets/highlights/developer-program-member.svg" width="56"> | **Developer Program Member** | Register for the [GitHub Developer Program](https://docs.github.com/en/get-started/exploring-integrations/github-developer-program). You need to be building something that integrates with GitHub (an app, action, or API tool) | ✅ |
| <img src="../assets/highlights/security-bug-bounty-hunter.svg" width="56"> | **Security Bug Bounty Hunter** | Submit an eligible, valid vulnerability report to the [GitHub Security Bug Bounty](https://bounty.github.com) on HackerOne | ✅ (skill needed) |
| <img src="../assets/highlights/security-advisory-credit.svg" width="56"> | **Security Advisory Credit** | Be credited on a security advisory that GitHub has reviewed in the [GitHub Advisory Database](https://github.com/advisories), for example by finding and reporting a vulnerability, or by submitting an advisory improvement that gets merged | ✅ (skill needed) |
| <img src="../assets/highlights/campus-expert.svg" width="56"> | **GitHub Campus Expert** | Apply to and finish training for the [Campus Experts](https://education.github.com/experts) program while a student | 🎓 Students |
| <img src="../assets/highlights/github-star.svg" width="56"> | **GitHub Star** | Be nominated and selected for the [GitHub Stars](https://stars.github.com) program, which recognises community leaders and educators | 🌟 By nomination |
| <img src="../assets/highlights/staff.svg" width="56"> | **Staff** | Work at GitHub | 🏢 Employees |

## Tips

- **Security Advisory Credit, the accessible route:** on any advisory page in the Advisory Database, click **Suggest improvements for this vulnerability** and fix missing affected versions, CWE IDs or references. If a curator merges your change, you're credited.
- **PRO** goes away when your Pro subscription ends. The others stay as long as you remain in the program.
